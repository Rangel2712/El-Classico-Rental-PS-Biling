# El Classico Rental PS Billing

Billing otomatis rental PS lewat WiFi: Smart TV (APK), aplikasi Windows (.exe) dan Mac (.dmg), serta panel kasir di browser.

- 📖 Panduan lengkap: [PANDUAN.md](PANDUAN.md)
- ▶️ Coba cepat: `cd server && node server.js` → buka http://localhost:8080 (PIN `1234`)
- 📺 Layar TV via browser: http://localhost:8080/tv?unit=tv1
- 🏗️ File APK/EXE/DMG dibuat otomatis oleh GitHub Actions (tab **Actions** → Artifacts)
